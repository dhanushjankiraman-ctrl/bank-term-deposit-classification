# 🏦 Bank Term Deposit Classification

A Machine Learning classification project that predicts whether a customer will subscribe to a bank term deposit using customer and campaign-related information.

## 📌 Project Overview

This project applies supervised machine learning techniques to a bank marketing dataset.

The objective is to classify customers into two categories:

- ✅ Term Deposit Subscription
- ❌ No Term Deposit Subscription

The project includes data preprocessing, exploratory data analysis, model training, hyperparameter tuning, and model evaluation.

## 🎯 Objective

The main objective of this project is to build a classification model that can:

- Analyze customer and campaign-related features
- Predict term deposit subscription
- Compare different classification algorithms
- Evaluate model performance using classification metrics
- Identify a model with good generalization performance
